# HeavenCombatAssist

FF14 卫月（Dalamud / Stellar）**战斗输出辅助**插件。按职业用 JSON 脚本配置技能与施放条件，支持分类开关、热键与自动循环。

## 主要功能

- **按职业独立脚本**  
  每个战斗职业（含剑术师、秘术师等前置职业）一份配置，可在「默认 / 自定义」配置间切换。

- **技能列表与优先级**  
  列表从上到下为优先级；支持拖拽排序。可按技能 ID 或中/英文名搜索并添加技能（本地中英名称库）。

- **技能分类**  
  默认分类：`CD` / `AOE` / `生存`，也可自行添加、删除。技能可属于多个分类；**所勾选分类全部开启**时才会施放。

- **施放条件**  
  条件组内为「与」、组间为「或」。支持战斗中、目标、敌对数量、自身/目标 HP、连击、职业量谱、**技能 CD**、**状态时间 / 状态层数**、**是否移动**等。

- **GCD / 能力技时机**  
  可在插件配置中调整 GCD 提前量与能力技插入窗口。

- **总开关 = 自动循环**  
  首页大开关同时控制插件启用与自动输出循环。

- **热键**  
  可为分类或单个技能绑定 HotKey（切换分类 / 触发施放）。

- **分类面板**  
  无边框按钮网格，方便战斗中快速开关各类技能。

- **多语言**  
  插件界面与技能显示名跟随「插件配置」中的中文 / English。

## 安装

1. 将本仓库全部文件放到同一目录（保持 `Data/`、`Scripts/` 与 dll 相对位置）。
2. 在卫月中添加该目录为开发插件路径并启用 **HeavenCombatAssist**。
3. 游戏内输入 `/hca` 打开主界面。

## 常用命令

| 命令 | 说明 |
|------|------|
| `/hca` | 打开主界面 |
| `/hca on` / `off` / `toggle` | 开启 / 关闭 / 切换自动循环 |
| `/hca reload` | 重新加载当前职业脚本 |

## 目录说明

| 路径 | 说明 |
|------|------|
| `HeavenCombatAssist.dll` | 插件本体 |
| `HeavenCombatAssist.json` | 插件清单 |
| `Data/action-names.json` | 技能中英文名称库 |
| `Scripts/*.json` | 各职业默认脚本（空技能列表，自行添加） |
| `latest.zip` | 打包备用 |

## 使用提示

1. **默认配置只读**，请先「新建自定义配置」再添加技能、改条件。  
2. 自定义配置一般保存在卫月插件配置目录下的 `HeavenCombatAssist/Scripts/<职业>/`。  
3. 修改后记得在技能配置页保存 JSON。

## 外部控制（IPC）

前缀：`HeavenCombatAssist.`  
可供其他插件开关总开关、分类/技能，或按脚本 id / ActionId 触发施放。详见源码仓库或插件内说明。
